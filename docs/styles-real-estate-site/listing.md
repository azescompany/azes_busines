## Section order (implemented)

1. Breadcrumb (Home › Type › Title) + Share / Favorite / Compare
2. Title block + status badges + price + /m²
3. Media tabs: Gallery / Map (Video/Tour hide when no data)
4. Two columns: content (Overview, Description, Details, Address, Features, Mortgage CTA, Schedule Tour, Similar) · sticky agent + LeadForm
5. Mobile bottom CTA: Call / WhatsApp
